## The problem

Release notes at work were either a raw commit dump or skipped entirely, so nobody outside the team knew what had shipped.

## Constraints

- Must run locally and in CI with one command.
- Commits stay on the machine unless the user opts in to the AI summary.

## Key decisions

**Group by conventional commit type first.** Most of the structure comes for free from commit prefixes; the model only rewrites each group into plain English.
